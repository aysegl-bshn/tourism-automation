## 🇬🇧 English

### 📌 About the Project

This project is a **Tourism Automation Database** developed to manage customer, tour, guide, and reservation information using a relational database structure.

The project was developed using **Microsoft SQL Server**.

### 🛠️ Technologies Used

* Microsoft SQL Server
* SQL
* ER Diagram
* Database Normalization
* JOIN
* GROUP BY
* HAVING
* CRUD Operations
* Primary Key / Foreign Key

### 🗄️ Database Features

* Relational database structure
* Primary Key and Foreign Key relationships
* One-to-many relationships
* Many-to-many relationships
* 3NF normalization
* JOIN queries
* GROUP BY and HAVING queries
* CRUD operations
* Data integrity

### 🎯 Project Purpose

The aim of this project is to create a structured and manageable relational database system that can be used for basic tourism business operations.
